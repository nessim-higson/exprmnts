# 005 · Text Nav, Knockout

005 with every word cut out of the page. The weight decides how much of the work shows through.

- **The wall:** all 109 thumbnails mined from `portfolio.swf`, drawn at 3× with hard pixels as one slowly travelling mosaic that leans with the pointer. Its blacks are lifted so a letter never opens onto black.
- **The surface:** a canvas with the nav punched out (`destination-out`). The stroke trick from the Helvetica version gives continuous weight: the live column is a Bold window, a selection and a hover open it further, and ancestors thin to Light hairlines and fade. The one red item, "Firstborn is 5!", stays solid red.
- The words stay in the DOM, transparent, so clicks, focus, keyboard and screen readers work as in 005. The canvas reads their positions every frame.
- Dark by default, with Light in the top bar. Same grid (G) and physics panel.
