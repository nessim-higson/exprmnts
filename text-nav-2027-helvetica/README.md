# 005 · Text Nav, Helvetica

005 set in Helvetica Neue, as a Swiss piece on paper. Same engine and content as `../text-nav-2027/`.

- **Real cuts only.** The live column and the selected path are Medium in ink. Everything that has stepped back is Regular in grey. Size, colour and tracking carry the rest of the hierarchy. (An earlier version faked continuous weight with a text stroke. It looked wrong at display sizes, so it's gone.)
- **Tracking follows size**: −0.048em at full size, opening to about −0.004em as a column recedes.
- **Sentence case**, keeping the 2003 copy's proper nouns (Firstborn, Michael Ferdman, Calvin Klein, CD-ROMs, …).
- **Catalogue numbers** hang in the gutter of the live column, and child counts are tabular superscripts.
- **G, or the Grid button,** shows the twelve-column grid and 8px baseline.
- The IAAH version of this study is in the living site, `l-index/`.
