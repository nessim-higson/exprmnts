# 005 · Text Nav, Helvetica

005 set in Helvetica Neue, as a Swiss piece on paper. Same engine and content as `../text-nav-2027/`.

- **One face, one weight.** Everything is Helvetica Neue Light, and a text stroke drawn under the fill adds weight continuously. The stem gains exactly the stroke width, so weight can animate without the line reflowing. The live column sits at about Medium, a selection at about Bold, a hover swells a little, and ancestors fall back to Light.
- **Tracking follows size**: −0.052em at full size, opening to about −0.006em as a column recedes.
- **Sentence case**, keeping the 2003 copy's proper nouns (Firstborn, Michael Ferdman, Calvin Klein, CD-ROMs, …).
- **Catalogue numbers** hang in the gutter of the live column, and child counts are tabular superscripts.
- **G, or the Grid button,** shows the twelve-column grid and 8px baseline the page is set on.
- Copy sits under every column on a phone, never only under the live one.
